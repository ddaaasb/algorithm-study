# 05 동적 계획 알고리즘

---

<aside>
💡

동적 계획 알고리즘은 입력 크기가 작은 부분문제들을 모두 해결한 후,

그 해를 이용하여 보다 큰 크기의 부분문제를 해결하여,

원래 주어진 입력의 문제를 해결하는 알고리즘이다.

</aside>

![image.png](image.png)

- 분할 정복 알고리즘은 부분문제의 해를 중복 사용하지 않는 반면, 동적 계획 알고리즘은 그렇다.
    - 동적 계획 알고리즘에는 부분문제들 사이 의존적 관계가 존재한다.
    - 이를 함축적 순서(implicit order)라고 한다.

# 5.1 모든 쌍 최단 경로

- 모든 쌍 최단 경로는 각 점을 시작점으로 정해 다익스트라 알고리즘을 수행해 해결할 수 있다.
- 이때의 시간복잡도는 아래와 같다.

$$
(n-1)*O(n^2)=O(n^3)
$$

![KakaoTalk_20250714_094646173.jpg](KakaoTalk_20250714_094646173.jpg)

- 동적 계획 알고리즘인 플로이드-워셜 알고리즘은 동일한 시간복잡도를 가지나, 매우 간단해 효율적이다.
- 동적 계획 알고리즘으로 모든 쌍 최단 경로 문제를 해결하기 위해 부분문제들을 찾는다:
    - 그래프의 점의 수가 적은 경우의 예시를 든다.
    - 점 i에서 점 j까지의 최단 경로를 찾기 위해 직접 가는 경로와 경유하는 경로 중 짧은 것을 선택한다.
    - 경유 가능한 점을 점 1로부터 시작해, 하나씩 추가하여 점 n까지의 모든 점을 경유 가능 점으로 고려.
        - 모든 쌍의 최단 경로의 거리를 계산한다.
- 위 아이디어를 이용해 다음과 같은 부분문제를 만들 수 있다:

![KakaoTalk_20250714_095456819.jpg](KakaoTalk_20250714_095456819.jpg)

```c
입력: 2차원 배열 D, 단, D[i, j]=간선 (i, j)의 가중치, 만일 간선 (i, j)이 존재하지 않으면
D[i, j]=infinity, 모든 i에 대하여 D[i, i]=0이다.
출력: 모든 쌍 최단 경로의 거리를 저장한 2차원 배열 D
for k = 1 to n
	for i = 1 to n (단, i != k)
		for j = 1 to n (단, j != k, j != i)
			D[i, j] = min{D[i, k] + D[k, j] + D[i, j]}
```

$$
O(n^3)
$$

# 5.2 연속 행렬 곱셈

- 연속 행렬 곱셈은 연속된 행렬들의 곱셈에 필요한 원소 간의 최소 곱셈 횟수를 찾는 문제이다.
    - 연속된 행렬의 곱셈에는 결합 법칙이 허용된다.
    - 필요한 원소 간의 곱셈 횟수를 최소화시키기 위해서는 적절한 행렬의 곱셈 순서를 찾아야 한다.
- 행렬 곱셈은 행과 열의 크기에 따라 그 순서가 정해지고, 순서가 곧 부분문제가 된다.

```c
입력: 연속된 행렬 A1*A2*…*An, 단, A1은 d1*d2, …, An은 dn-1*dn이다.
출력: 입력의 행렬 곱셈에 필요한 원소 간의 최소 곱셈 횟수
for i = 1 to n
	C[i, i] = 0
for L = 1 to n-1 {
	for i = 1 to n-L {
		j = i + L
		C[i, j] = infinity
		for k = i to j-1 {
			temp = C[i, k] + C[k+1, j], + di-1dkdj
			if (temp < C[i, j])
				C[i, j] = temp
		}
	}
}
return C[1, n]
```

$$
O(n^2)*O(n)=O(n^3)
$$

# 5.3 편집 거리 문제

<aside>
💡

문서 편집기 사용 중 스트링 S와 T에 대해, S를 T로 변환시키는 데 필요한 최소 편집 연산 횟수.

</aside>

- 편집 거리 문제를 동적 계획 알고리즘으로 해결하기 위해 부분문제를 다음과 같이 표현한다:
    - 각 접두부에 대해 편집 거리를 미리 알고 있는 경우 편집 연산 횟수를 줄일 수 있다.
    - 스트링 S와 T의 길이가 m, n이라 하고, 각 문자를 si, tj라 하면 i=1, 2, …, m이고 j=1, 2, …, n이다.
- 부분문제를 다음과 같이 정의한다:
    - E[i, j]는 S의 접두부 i개 문자를 T의 접두부 j개 문자로 변환시키는 데 필요한 편집 거리이다.
        - stro를 sto로 바꾸기 위한 편집 거리를 찾는 문제는 E[4, 3]이다.

```c
입력: 스트링 S, T, 단, S와 T의 길이는 각각 m과 n이다.
출력: S를 T로 변환하는 편집 거리, E[m, n]
for i=0 to m E[i, 0] // 0번 열의 초기화.
for j=0 to n E[0, j] // 0번 행의 초기화.
for i=1 to m
	for j=1 to n
		E[i, j] = min{E[i, j-1]+1, E[i-1, j]+1, E[i-1, j-1]+a}
return E[m, n]
```

- 시간복잡도는 다음과 같다:

$$
O(mn)
$$

# 5.4 배낭 문제

<aside>
💡

배낭 문제는 n개의 물건, 물건 i의 무게 wi와 가치 vi가 주어지고, 용량 C에 대해 담을 수 있는

물건의 최대 가치를 찾는 문제이다.

</aside>

- 배낭 문제는 제한적인 입력에 대해 동적 계획 알고리즘으로 해결할 수 있다.
- 배낭 문제의 부분문제를 다음과 같이 정의한다:
    - K[i, w]=물건 1~i까지만 고려하고, 임시 배낭 용량이 w일때 최대 가치.
    - 단, i = 1, 2, …, n이고, w = 1, 2, 3, …, C이다.
- 문제의 최적해는 K[n, C]이다.

```c
입력: 배낭의 용량 C, n개의 물건과 각 물건 i의 무게 wi와 가치 vi, 단, i = 1, 2, …, n
출력: K[n, C]
for i = 0 to n K[i, 0]=0 // 배낭의 용랴이 0일 때
for w = 0 to C K[0, w]=0 // 물건 0이란, 어떤 물건도 배낭에 담기 위해 고려하지 않았을 때

for i = 1 to n {
	for w = 1 to C {
		if (wi > w)
			K[i, w] = K[i-1, w]
		else
			K[i, w] = max{K[i-1, w], K[i-1, w-wi]+vi}
	}
}
return K[n, C]
```

# 5.5 동전 거스름돈

<aside>
💡

동적 계획 알고리즘은 모든 동전 거스름돈 문제에 대해 항상 최적해를 찾는다.

</aside>

- 동적 계획 알고리즘을 고안하기 위해 부분문제를 찾는다.
    - 동전 거스름돈 문제도 1원씩 증가시켜 문제를 해결한다.
    - 거스름돈을 배낭의 용량으로 생각하고, 동전을 물건이라 생각한다.

![KakaoTalk_20250714_144744945.jpg](KakaoTalk_20250714_144744945.jpg)

![KakaoTalk_20250714_144744945_01.jpg](KakaoTalk_20250714_144744945_01.jpg)

```c
입력: 거스름돈 n원, k개의 동전의 액면, d1>d2>…>dk=1
출력: C[n]
for i = 1 to n C[i] = infinity
C[0] = 0
for j = 1 to n {
	for i = 1 to k {
		if (di<=j) and (C[j-di]+1<C[j])
			C[j] = C[j-di] + 1
	}
}
return C[n]
```

13. 플로이드 알고리즘은 모든 쌍의 최단 경로 거리만을 계산한다. 최단 경로를 찾을 수 있도록 수정된 알고리즘을 작성하라.
    - 우선 모든 쌍의 최단 경로 거리를 찾는 알고리즘은 다음과 같다:
    
    ```c
    입력: 2차원 배열 D, 단, D[i, j]=간선 (i, j)의 가중치, 만일 간선 (i, j)이 존재하지 않으면
    D[i, j]=infinity, 모든 i에 대하여 D[i, i]=0이다.
    출력: 모든 쌍 최단 경로의 거리를 저장한 2차원 배열 D
    for k = 1 to n
    	for i = 1 to n (단, i != k)
    		for j = 1 to n (단, j != k, j != i)
    			D[i, j] = min{D[i, k] + D[k, j] + D[i, j]}
    ```
    
    - 이제 이를 수정한다:
    
    ```c
    입력: 2차원 배열 D, 단, D[i, j]=간선 (i, j)의 가중치, 만일 간선 (i, j)이 존재하지 않으면
    D[i, j]=infinity, 모든 i에 대하여 D[i, i]=0이다.
    출력: 모든 쌍 최단 경로의 거리를 저장한 2차원 배열 D, 경로 배열 P
    for k = 1 to n
    	for i = 1 to n (단, i != k)
    		for j = 1 to n (단, j != k, j != i)
    			if (D[i][k] + D[k][j] < D[i][j]) // 최단거리가 경유하는 경우가 더 짧은 경우,
    				D[i, j] = D[i, k] + D[k, j] // 최단 거리 업데이트.
    				P[i][j] = P[k][j] // 또한 최단 경로를 업데이트한다.
    ```
    
    - P[i][j]는 i에서 j까지로 가는 최단 경로에서 j에 도착하기 직전 노드를 저장한다.
        - D[i][j]가 $\infty$가 아닌 경우 P[i][j]=i로 초기화한다. j에 도착하기 직전 노드는 i 자신이다.
        - $\infty$인 경우 $null$로 초기화한다.

16. MatrixChain 알고리즘은 어떤 순서로 행렬의 곱셈이 진행되어야 하는지를 출력하지 않는다. 그 순서를 출력하도록 알고리즘을 수정하라.
    - 기존 알고리즘은 다음과 같다:
    
    ```c
    입력: 연속된 행렬 A1*A2*…*An, 단, A1은 d1*d2, …, An은 dn-1*dn이다.
    출력: 입력의 행렬 곱셈에 필요한 원소 간의 최소 곱셈 횟수
    for i = 1 to n
    	C[i, i] = 0
    for L = 1 to n-1 {
    	for i = 1 to n-L {
    		j = i + L
    		C[i, j] = infinity
    		for k = i to j-1 {
    			temp = C[i, k] + C[k+1, j], + di-1dkdj
    			if (temp < C[i, j])
    				C[i, j] = temp
    		}
    	}
    }
    return C[1, n]
    ```
    
    - 수정된 알고리즘은 다음과 같다:
    
    ```c
    // 입력: 연속된 행렬 A1*A2*...*An. 단, A1은 d1*d2, ..., An은 d(n-1)*dn이다.
    // 출력:
    // 1. 최소 원소 곱셈 횟수
    // 2. 최적 곱셈 순서를 나타내는 P 테이블
    
    // C[i, j]: Ai...Aj를 곱하는 데 필요한 최소 곱셈 횟수
    // P[i, j]: Ai...Aj를 곱하는 최적의 분할 지점 k
    MatrixChain(A, d, n) {
        for i = 1 to n
            C[i, i] = 0
    
        // P 테이블 초기화 (필수는 아님)
        // for i = 1 to n-1
        //     for j = i+1 to n
        //         P[i, j] = 0
    
        for L = 1 to n-1 {      // L은 행렬 체인의 길이
            for i = 1 to n-L {
                j = i + L
                C[i, j] = infinity
                for k = i to j-1 {
                    temp = C[i, k] + C[k+1, j] + d(i-1)*d(k)*d(j)
                    if (temp < C[i, j]) {
                        C[i, j] = temp
                        // 👇 핵심 수정 사항: 최소 비용을 만드는 k를 P[i, j]에 저장
                        P[i, j] = k
                    }
                }
            }
        }
        return C, P // 비용 테이블 C와 분할 지점 테이블 P를 반환
    }
    ```
    
    ```c
    // P: MatrixChain 알고리즘으로 계산된 분할 지점 테이블
    // i, j: 현재 출력하려는 행렬 체인의 시작과 끝 인덱스
    PrintOptimalParens(P, i, j) {

            print " * "

        }
    }
    ```

    ```c
    // S, T: 입력 문자열
    // E: 완성된 DP 행렬
    function getBacktrace(S, T, E):
      operations = [] // 연산을 저장할 리스트
      i = length(S)
      j = length(T)
    
      while i > 0 and j > 0:
        // 대체 또는 일치 비용 (S[i-1]과 T[j-1]이 같으면 0, 다르면 1)
        substitution_cost = (S[i-1] == T[j-1]) ? 0 : 1
    
        if E[i, j] == E[i-1, j-1] + substitution_cost:
          if substitution_cost == 1:
            operations.add("Substitute " + S[i-1] + " with " + T[j-1])
          else:
            operations.add("Match " + S[i-1])
          i = i - 1
          j = j - 1
        else if E[i, j] == E[i-1, j] + 1:
          operations.add("Delete " + S[i-1])
          i = i - 1
        else: // E[i, j] == E[i, j-1] + 1
          operations.add("Insert " + T[j-1])
          j = j - 1
    
      // 남은 문자 처리 (i 또는 j 중 하나만 0보다 클 경우)
      while i > 0:
        operations.add("Delete " + S[i-1])
        i = i - 1
      while j > 0:
        operations.add("Insert " + T[j-1])
        j = j - 1
    
      // 역순으로 기록되었으므로 리스트를 뒤집어서 반환
      return reverse(operations)
    ```

    ```c
    for w = 0 to C K[0, w]=0 // 물건 0이란, 어떤 물건도 배낭에 담기 위해 고려하지 않았을 때
    
    for i = 1 to n {
    	for w = 1 to C {
    		if (wi > w)
    			K[i, w] = K[i-1, w]
    		else
    			K[i, w] = max{K[i-1, w], K[i-1, w-wi]+vi}
    	}
    }
    return K[n, C]
    ```
    
    - 수정된 알고리즘은 다음과 같다:
    
    ```c
    입력: 배낭의 용량 C, n개의 물건과 각 물건 i의 무게 wi와 가치 vi, 단, i = 1, 2, …, n
    출력: K[n, C], P[n, C}
    for i = 0 to n K[i, 0]=0 // 배낭의 용랴이 0일 때
    for w = 0 to C K[0, w]=0 // 물건 0이란, 어떤 물건도 배낭에 담기 위해 고려하지 않았을 때
    
    for i = 1 to n {
        for w = 1 to C {
            if (wi > w) {
                K[i, w] = K[i-1, w];
                P[i][w] = P[i-1][w];
            }
            else {
                if (K[i-1, w] >= K[i-1, w-wi] + vi) {
                    K[i, w] = K[i-1, w];
                    P[i][w] = P[i-1][w];
                }
                else {
                    K[i, w] = K[i-1, w-wi] + vi;
                    P[i][w] = P[i-1][w-wi];
                    P[i][w].add(item i);
                }
            }
        }
    }
    
    return K[n, C], P[n][C];
    ```

30. 배낭 문제는 각 물건이 1개씩만 있다. 이 문제에서 각 물건의 개수가 충분할 때 최적해를 찾는 동적 계획 알고리즘을 작성하라. 단, W는 배낭의 용량, n은 물건의 수, wi와 vi는 물건 i의 무게와 가치이다. 그리고 알고리즘의 시간복잡도를 계산하라.
    - 무제한 배낭 문제의 최적해를 찾는 알고리즘이 필요하다:
    
    ```python
    def zero_one_knapsack(C, n, weights, values):
        """
        0/1 배낭 문제의 최적해를 찾는 동적 계획법 알고리즘
    
        Args:
            C (int): 배낭의 총 용량
            n (int): 물건의 수
            weights (list): 각 물건의 무게 리스트 (w_1, w_2, ...)
            values (list): 각 물건의 가치 리스트 (v_1, v_2, ...)
    
        Returns:
            int: 배낭에 담을 수 있는 물건들의 최대 가치 합
        """
        # K[i][w]: i개의 물건을 사용하여 용량 w를 채울 때의 최대 가치
        # (n+1) x (C+1) 크기의 2차원 배열 생성
        K = [[0 for _ in range(C + 1)] for _ in range(n + 1)]
    
        # i는 물건 번호, w는 배낭 용량
        for i in range(1, n + 1):
            for w in range(1, C + 1):
                # i번째 물건의 무게와 가치 (인덱스는 i-1)
                wi = weights[i-1]
                vi = values[i-1]
    
                # i번째 물건의 무게가 현재 용량 w보다 크면 넣을 수 없음
                if wi > w:
                    K[i][w] = K[i-1][w]
                else:
                    # i번째 물건을 넣지 않는 경우와 넣는 경우 중 최대값 선택
                    not_included = K[i-1][w]
                    included = K[i-1][w - wi] + vi
                    K[i][w] = max(not_included, included)
    
        # 최종 결과는 K[n][C]에 저장됨
        return K[n][C]
    
    # 예제 사용법
    C = 50  # 배낭 용량
    weights = [10, 20, 30]  # 물건들의 무게
    values = [60, 100, 120]  # 물건들의 가치
    n = len(weights)  # 물건의 수
    
    max_value = zero_one_knapsack(C, n, weights, values)
    print(f"배낭 용량 {C}으로 얻을 수 있는 최대 가치: {max_value}")
    # 예상 출력: 배낭 용량 50으로 얻을 수 있는 최대 가치: 220
    # (무게 20, 가치 100인 물건과 무게 30, 가치 120인 물건을 담는 경우)
    ```

        $$
        C[i, j] = \begin{cases} C[i-1, j-1] + 1 & \text{if } x_i = y_j \\ 0 & \text{if } x_i \neq y_j \end{cases}
        $$
        
    - 알고리즘은 n*m 크기의 동적 계획법 C 테이블을 채워야 한다. 따라서 시간 복잡도는 $O(mn)$.

    - C[i][j]를 $x_i$로 시작하고 $y_j$로 끝나는 연속된 공통 부분 순서의 길이라 정의한다.
        - C[i][j]는 다음의 순환 관계를 따른다.
        
        $$
        C[i, j] = 
        \begin{cases} 
        C[i-1, j-1] + 1 & \text{if } x_i = y_j \\
        \max(C[i-1, j], C[i, j-1]) & \text{if } x_i \neq y_j 
        \end{cases}
        $$
        
    - 알고리즘은 (n-1)*(m-1) 크기의 동적 계획법 C 테이블을 채워야 한다. 시간 복잡도는 $O(mn)$.

        P[i, j] =\begin{cases}1 & \text{if } i = j \\P[i+1, j-1] + 2 & \text{if } i < j \text{ and } s_i = s_j \\\max(P[i+1, j], P[i, j-1]) & \text{if } i < j \text{ and } s_i \neq s_j\end{cases}

39. 어느 공장의 생산 라인에 있는 로봇은 눈금이 1부터 n까지 표시되어 있는 수직선상으로 움직인다. 그런데 로봇은 한 번의 움직임으로 좌표 i에서 i+1, i+2, ..., i+k로 이동할 수 있다. 초기에 로봇이 좌표 1에 있다면, 로봇이 좌표 n까지 이동하는데 서로 다른 움직이는 방법의 수를 계산하는 동적 계획 알고리즘을 위한 순환 관계를 제시하고, 알고리즘의 시간복잡도를 구하라. 단, n과 k는 양수이고, n≥k이다. 예를 들어 k=3이면서 로봇이 좌표 1에서 좌표 4까지 이동할 수 있는 서로 다른 움직이는 방법의 수는 다음 그림과 같이 4이다.
    - D[i]를 로봇이 좌표 1에서 시작하여 좌표 i까지 도달하는 서로 다른 방법의 수라 정의한다.
        - 로봇이 좌표 i에 도달하기 위해, i-1 및 i-k 사이 한 곳에 존재해야 한다.
        - 따라서 i에 도달하는 방법의 수는 이전에 있을 수 있었던 각 좌표에 도달하는 방법의 수.
        
        $$
        D[i] = \sum_{j=1}^{k} D[i-j]
        $$
        
    - 로봇은 좌표 1에서 시작하므로 D[1] = 1이다. 따라서 시간복잡도는 $O(nk)$.
    
    ---
    
    - D[i]는 D[i-1]에 D[i-1]을 더하고 범위를 벗어난 D[i-k-1]을 뺀 값과 같다.
    
    $$
    D[i] = D[i-1] + D[i-2] + \dots + D[i-k]
    $$
    
    - D[i]와 D[i-1]로 정리하면 다음과 같은 점화식을 얻을 수 있다.
    
    $$
    D[i] = 2 \times D[i-1] - D[i-k-1]
    $$
    
    - 최적화된 점화식에서의 시간복잡도는 $O(n)$.
40. n개의 정수가 나열되어 있을 때 숫자들의 증가 순서(increasing sequence)들 중에서 가장 긴 것의 길이를 계산하는 동적 계획 알고리즘을 위한 순환 관계를 제시하고, 알고리즘의 시간복잡도를 구하라. 증가 순서에 있는 숫자들은 반드시 이웃할 필요는 없다. 예를 들어 4 1 7 5 2 5 8 6에서 1 2 5 8이 가장 긴 증가 순서이다.
    - 주어진 정수 배열 A에 대해 D[i]를 A[i]를 마지막 원소로 포함하는 긴 증가 순서의 길이라 하자.
        - D[i] = 1 + max({D[j]})
        
        ```python
        # O(n^2) 알고리즘 의사코드
        def lis_length(A):
          n = len(A)
          if n == 0:
            return 0
          
          D = [1] * n # 각 D[i]를 1로 초기화
          
          for i in range(1, n):
            for j in range(i):
              if A[j] < A[i]:
                D[i] = max(D[i], D[j] + 1)
                
          return max(D)
        ```
        
    - 이중 반복문이므로 $O(n^2)$.
