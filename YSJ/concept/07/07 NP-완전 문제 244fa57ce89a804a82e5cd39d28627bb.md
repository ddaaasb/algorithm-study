# 7.1 문제 분류

- 컴퓨터로 풀 수 있는 모든 문제는 문제를 해결하는 알고리즘의 시간복잡도에 따라 분류될 수 있다.
    - 다항식 시간복잡도를 가진 알고리즘으로 해결되는 P(polynomial) 문제 집합.
    - 다항식보다 큰 시간복잡도를 가진 알고리즘으로 해결되는 문제 집합.
- 7장 이전의 문제들은 P 문제 집합에 속한다.
- 다항식보다 큰 시간복잡도의 문제는 여럿 있으나, 가장 중요한 것은 NP-완전 문제이다.
    - NP-완전 문제는 지수 시간의 시간복잡도를 가진다.
    - 어느 하나의 NP-완전 문제에 대해서 다항식 시간에 해결되면, 모든 다른 NP-완전 문제도 동일하다.

<aside>
💡

NP 알고리즘은 첫 번째 단계에서 주어진 입력에 대해 하나의 해를 ‘추측하고,’

두 번째 단계에서 그 해를 다항식 시간에 확인한 후에, 그 해가 ‘맞다’ 또는 ‘아니다’라고 답한다.

</aside>

- P 문제 집합과 NP-완전 문제 집합을 둘 다 포함하는 집합인 NP 문제 집합이 있다.
    - NP 문제는 비결정적 다항식 시간 알고리즘을 가진 문제이다.
    - NP 알고리즘은 해를 찾는 알고리즘이 아니라 해를 다항식 시간에 확인하는 알고리즘이다.

![22058.jpg](22058.jpg)

- P 문제를 위한 NP 알고리즘은 해를 추측하는 단계를 생략하고, 해를 다항식 시간에 구하고 ‘맞다’ 답한다.

# 7.2 NP-완전 문제의 특성

- NP-완전 문제의 특성을 알기 위해 다른 문제로 변환 또는 환원하는 과정을 이해해야 한다.

![22059.jpg](22059.jpg)

- 문제 A를 부분 집합의 합 문제라 하고, 문제 B를 ‘동일한 크기의’ 분할 문제라고 한다.

![22060.jpg](22060.jpg)

- 부분 집합의 합 문제의 입력인 집합 S를 분할 문제의 입력으로 변환할 때에 t를 S에 추가한다.
    - 단 s는 집합 S의 모든 원소의 합이다.

$$
t=s-2K
$$

- 부분 집합의 합 문제를 해결하기 위해 $S'=S\cup\{t\}$를 입력으로 하는 분할 문제를 위한 알고리즘 활용.
- 분할 문제 알고리즘의 해인 2개의 집합 X와 Y에 대해, 원소의 합이 같으므로, 각각의 합은 $(s-K)$이다.
    - 새 집합 $S'$의 모든 원소의 합이 $s+t=s+(s-2K)=2s-2K$이다.
- 따라서 분할 문제의 해인 X와 Y 중에서 t를 가진 집합에서 t를 제거한 집합이 부분 집합의 합 문제의 해.
    - X에 t가 속해 있는 경우, X에서 t를 제외한 원소 합은 아래와 같아 합 문제의 해는 $X-\{t\}$이다.
    - $(s-K)-t=(s-K)-(s-2K)=s-K-s+2K=K$

![22061.jpg](22061.jpg)

- 첫 번째와 세 번째는 단순 입출력 변환이므로 다항식 시간에 수행된다.
- 두 번째 단계의 시간복잡도에 따라 문제 변환의 시간복잡도가 결정된다.

![22062.jpg](22062.jpg)

- 문제 A와 문제 B 사이에 이러한 관계가 성립하면, A가 B로 변환(polynomial time reduction) 가능.
- 문제 B가 문제 C로 다항식 시간에 변환 가능하면, 문제 A가 문제 C로 변환 가능하다.
    - 이러한 추이(transitive) 관계로 NP-완전 문제들이 서로 얽여 있어, 하나만 해결되면 다 해결된다.
- NP-하드(hard) 문제 집합을 다음과 같이 정의한다.

<aside>
💡

어느 문제 A에 대해서, 만일 모든 NP 문제가 문제 A로 다항식 시간에 변환이 가능하다면,

문제 A는 NP-하드 문제이다.

</aside>

- 모든 NP 문제가 NP-하드 문제로 다항식 시간에 변환 가능함에도, NP-하드 문제는 NP 문제일 필요 없다.

![22063.jpg](22063.jpg)

- NP-완전 문제는 NP-하드 문제이면서 동시에 NP 문제이다.
- 따라서 NP-완전 문제는 다음과 같이 더욱 정확히 정의된다.

<aside>
💡

문제 A가 NP-완전 문제가 되려면, A는 NP 문제이고, A는 동시에 NP-하드 문제이다.

</aside>

# 7.3 NP-완전 문제의 소개

- **SAT**(Satisfiability)
    - 부울 변수들이 OR로 표현된 논리식이 여럿 주어질 때, 모두 만족하는 각 값을 찾는 문제.
- **부분 집합의 합**(Subset Sum)
    - 주어진 정수 집합 S의 원소의 합이 K가 되는 S의 부분 집합을 찾는 문제이다.
- **분할**(Partition)
    - 주어진 정수 집합 S를 분할하여 원소의 합이 같은 2개의 부분 집합 X와 Y를 찾는 문제이다.
- **0-1 배낭**(Knapsack)
    - 배낭의 용량 C에서 배낭에 담을 수 있는 물건의 최대 가치를 찾는 문제이다.
- **정점 커버**(Vertex Cover)
    - 그래프에서 각 간선의 양 끝점들 중 적어도 1개의 점을 포함하는 점의 집합을 정점 커버라 한다.
    - 정점 커버 문제는 최소 크기의 정점 커버를 찾는 문제이다.
- **독립 집합**(Independence Set)
    - 그래프에서 서로 연결하는 간선이 없는 점들의 집합을 독립 집합이라 한다.
    - 독집 집합 문제는 최대 크기의 독립 집합을 찾는 문제이다.
- **클리크**(Clique)
    - 그래프에서 모든 점들 사이를 연결하는 간선이 있는 부분 그래프를 클리크라 한다.
    - 클리크 문제는 최대 크기의 클리크를 찾는 문제이다.
- **그래프 색칠하기**(Graph Coloring)
    - 그래프에서 인접한 점들을 서로 다른 색으로 색칠할 때, 가장 적은 수의 색을 사용하는 문제이다.
- **집합 커버**(Set Cover)
    - 주어진 집합 S에 대해 S의 부분 집합들이 주어질 떄, 합하여 S와 같게 되는 부분을 집합 커버라 한다.
    - 집합 커버 문제는 가장 적은 수의 부분 집합으로 이루어진 집합 커버를 찾는 문제이다.
- **최장 경로**(Longest Path)
    - 그래프에서 시작점 s에서 도착점 t까지의 가장 긴 경로를 찾는 문제이다.
    - 간선의 가중치는 양수이고, 찾는 경로에는 반복되는 점이 없어야 한다.
- **여행자**(Traveling Salesman) **문제**
    - 그래프에서 임의의 한 점에서 출발하여 다른 모든 점들은 1번씩만 방문하고, 시작점으로 돌아온다.
    - 위 경로 중 최단 경로를 찾는다.
- **해밀토니안 사이클**(Hamiltonian Cycle)
    - 그래프에서 임의의 한 점에서 출발하여 모든 다른 점들을 1번씩만 방문하고, 시작점으로 돌아온다.
    - 간선의 가중치를 모두 동일하게 하여 여행자 문제의 해를 찾았을 때 해가 해밀토니안 사이클의 해.
- **통 채우기**(Bin Packing)
    - n개의 물건이 주어지고, 통의 용량이 C일 때, 가장 적은 수의 통을 사용하여 모든 통에 채우는 문제.
    - 물건의 크기는 C보다 크지 않다.
- **작업 스케줄링**(job Scheduling)
    - n개의 작업, 작업의 수행 시간 $t_i$, 그리고 m개의 동일 성능 기계가 주어질 때, 빨리 종료되도록 배정.

# 7.4 NP-완전 문제들의 활용

- **SAT 문제**
    - 전자 디자인 자동화
    - 형식 동치 관계 검사
    - 모델 검사
    - 형식 검증
    - 자동 테스트 패턴 생성
    - 지식 컴파일
    - 단상형 추론
    - 소프트웨어 검증
    - 자동 정리 증명
- **부분 집합의 합 문제**
    - 전자 태그 암호 시스템
    - 격자 기반 암호화 시스템
    - 공개 암호 시스템
    - 컴퓨터 패스워드 검사 및 메시지 검증
- **분할 문제**
    - Switching Network에서 채널 그래프 비교
    - 컨테이너의 효율적 배치
    - 네트워크 디자인
    - 인공 지능 신경망 네트워크의 학습
    - 패턴 인식
    - 로봇 동작 계획
    - 회로 및 VSLI 디자인
    - 의학 전문가 시스템
    - 유전자의 군집화
- **0-1 배낭 문제**
    - 금융 포트폴리오 선택
    - 자산 투자의 선택
    - 주식 투자
    - 다차원 경매
    - 암호 생성
    - 스도쿠
- **정점 커버 문제**
    - 부울 논리 최소화
    - 센서 수 최소화
    - 무선 통신
    - 토목 공학
    - 전기 공학
    - 최적 회로 설계
    - 네트워크 플로우
- **집합 커버 문제**
    - 비행기 조종사 스케줄링
    - 조립 라인 균현화
    - 정보 검색
    - 도시 계획
- **독집 집합**
    - 컴퓨터 비전
    - 패턴 인식
    - 정보/코딩 이론
    - 지도 레이블링
    - 분자 생물학
    - 스케줄링
    - 회로 테스트
    - CAD
- **클리크 문제**
    - 유전자 표현 데이터의 군집화
    - 단백질 구조 예측 연구
    - 단백질 특성 연구
- **그래프 색칠하기**
    - 생산 라인, 시간표 등의 스케줄링
    - 무선 네트워크에서 주파수 할당
    - 컴파일러의 프로그램 최적화
    - 패턴 인식
    - 데이터 압축
- **최장 경로 문제, 여행자 문제, 해밀토니안 사이클 문제**
    - 운송 및 택배 사업에서의 차량 운행
    - 가전 수리 및 케이블 회사에서의 서비스콜의 스케줄링
- **통 채우기 문제**
    - 다중 처리 장치 스케줄링
    - 멀티 미디어 저장 장치 시스템
    - 자원 할당
- **작업 스케줄링 문제**
    - 운영 체제의 작업 스케줄링
    - 다중 프로세서 스케줄링
    - 웹 서버에서 사용자 질의 처리
    - 주파수 대역 스케줄링
    - 공장 스케줄링

    - 풀이 및 답안은 다음과 같다:
        - 해밀토니안 사이클 문제의 역이다. HC에서 co-HC인 것이다.
        - 사이클이 없다는 것을 증명하기 위해서는 가능한 모든 경우를 보여야 한다.
        - 따라서 위 문제는 NP에 속한다.

    각 변수가 1번만 사용되는 SAT 문제
    
    단, 변수 x가 있다면 x 또는 overline x 중 1개만 주어진 논리식에 나타날 수 있다.
